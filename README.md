# ApaI — protected prompt generator

Бұл нұсқада сайттың өзін кез келген адам аша алады, бірақ промпт генераторы тек аккаунты бар, төлемі расталған және админ мақұлдаған қолданушыға жұмыс істейді.

## Қалай жұмыс істейді

1. Қонақ сайтты еркін көреді.
2. «Промпт жасау» батырмасын басса, тіркелу/кіру терезесі ашылады.
3. Жаңа қолданушы тіркелгенде profile автоматты түрде `pending + free` күйінде жасалады.
4. Төлем жасалғаннан кейін админ аккаунтты `Paid + Approve` арқылы белсендіреді.
5. Тек `approved + paid` (немесе `approved + admin`) аккаунт генерация жасай алады.
6. Промпттар Supabase-та user_id бойынша жеке сақталады. Бір қолданушы басқа адамның промптын көре алмайды.

## Supabase

`supabase-schema.sql` файлын Supabase SQL Editor ішінде толық орындаңыз.

Сайттың Supabase конфигурациясы `app.js` ішінде орнатылған.

> Браузерде anon/publishable key қолдануға болады. Service role key-ді сайтқа қоспау керек.

## Бірінші админді жасау

Өз аккаунтыңызды сайт арқылы тіркегеннен кейін, Supabase SQL Editor ішінде email-іңізді қойып мына SQL-ді бір рет орындаңыз:

```sql
update public.profiles
set access_status = 'approved', plan = 'admin', paid_until = null
where id = (select id from auth.users where email = 'YOUR_EMAIL');
```

Содан кейін сайтқа қайта кіріп, аккаунт терезесінен **Админ панелі** көрінеді.

## Төлем туралы

Бұл ZIP нақты төлем провайдерін (Kaspi/CloudPayments/PayBox және т.б.) қоспайды. Қазір төлемді сырттан қабылдап, админ панелінен қолданушыға `Paid + Approve` қоюға арналған қауіпсіз база логикасы бар.

Автоматты төлемнен кейін белсендіру үшін таңдалған төлем провайдерінің webhook/API интеграциясын серверлік функцияға қосу қажет.

## 1 айлық қолжетімділік жаңартуы

1. Supabase -> SQL Editor ашыңыз.
2. `subscription-update.sql` файлын толық іске қосыңыз.
3. Сайттың жаңартылған файлдарын GitHub-қа push жасаңыз.
4. Админ панельде әр қолданушыда `+1 ай` және `Блоктау` батырмалары, қалған уақыт және аяқталу күні көрінеді.
5. Мерзім аяқталса, қолданушының келесі сайт ашу/кіру әрекетінде ол автоматты түрде `blocked` болады; админ панель ашылғанда барлық мерзімі өткен аккаунттар да жаңартылады.
